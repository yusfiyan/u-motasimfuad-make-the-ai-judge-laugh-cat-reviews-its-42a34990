# One Star: A Cat Reviews Its Human

A single-line one-star review written by a house cat about its human,
for the
[Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/?ref=kgxbmb08&utm_source=github&utm_medium=readme&utm_campaign=u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990)
bounty on make.fun.

The review keeps the deadpan shape of a real one-star review while the
complaint goes somewhere only a cat would go: the human moved the cat
off his laptop mid-sentence — to type on a spreadsheet. *A spreadsheet.*
The sting lands in the last few words, where the cat reveals it
considers the human a creature it merely allows to feed it.

## The entry

> One star. He moved me off his laptop mid-sentence to type on a spreadsheet. A spreadsheet. I have never been so insulted by a creature I allow to feed me.

154 characters, one line, written by `main.ts` (Node 22, standard
library only) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Two runs from different working directories write byte-identical output.
